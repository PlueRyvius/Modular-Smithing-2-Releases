# Modular Smithing 2 — Releases

Download page for **Modular Smithing 2**, a crafting mod for Mount & Blade II: Bannerlord.

- **Latest build:** see [Releases](https://github.com/PlueRyvius/Modular-Smithing-2-Releases/releases/latest)
- **Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=3790263286

This repository holds release archives only. Each release here is mirrored automatically from the mod's development repository, with the same archive, checksum and notes.

## Installing from an archive

Do not extract over an existing `ModularSmithing2` folder.

1. Close Bannerlord.
2. Move any existing `Modules/ModularSmithing2` to a backup location outside `Modules`.
3. Extract the archive's `ModularSmithing2` folder into `Modules`.
4. Check that the launcher shows the version named in the release.

Each archive comes with a `.sha256` file for verifying the download.

## Requirements

- Mount & Blade II: Bannerlord v1.4.8
- Optional: Bannerlord Coop. Co-op is lockstep, so the host and every client must run the same Modular Smithing 2 version.
